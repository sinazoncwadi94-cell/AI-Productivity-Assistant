# WorkMate AI

Create an AI-powered workplace productivity application called WorkMate AI. It should help employees with everyday workplace tasks.Include an AI Email and Message Assistant that turns rough messages into professional communication, an AI Task Planner that prioritises tasks and creates a daily plan, a Meeting Notes Assistant that summarises notes and creates action items, a Daily Work Summary tool. Create a professional dashboard with sidebar navigation for all four tools. Make it modern, simple, responsive and easy to use. Include human oversight notices explaining that AI-generated content must be reviewed before use. Do not invent information the user has not provided. Build a complete working frontend.
